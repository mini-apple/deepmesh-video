# 데모 v2

배경 트래픽·k1·r1 실행 방법입니다. 모두 **k8s-master**에서, `~/deepmesh` 폴더 기준으로 실행합니다.

### 준비 (한 번)

```
cd ~/deepmesh && git pull
```

대시보드를 비웁니다(이전 판정 지우기):

```
bash scripts/demo.sh clean
```

### ① 배경 정상 트래픽

켜기 — 서비스 사이 초록 트래픽이 흐르고, external 간선도 생깁니다:

```
bash scripts/demo.sh live
```

끄기:

```
bash scripts/demo.sh quiet
```

### ② k1 — Kubernetes API 정찰 → 차단(DROP)

```
bash scripts/demo.sh k1
```

- auth Pod가 apiserver:443에 8번 요청 → 교차 검증이 차단.
- 끝에 `DROP 건수`가 1 이상이면 성공. 토폴로지에 `auth → Kubernetes API Server` 빨간 선이 뜹니다.

### ③ r1 — 응답 위조 XSS → 응답 대체(RELAY)

```
bash scripts/demo.sh r1
```

- frontend Pod의 index.html에 XSS를 넣고, post Pod가 그 Pod로 GET / 8번 → 응답 대체. 끝나면 원본 자동 복원.
- 끝에 `RELAY 건수`가 1 이상이면 성공. `frontend → post` 주황 선이 뜹니다.
