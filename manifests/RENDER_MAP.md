# RENDER_MAP — 렌더 단위 목록

단위 하나 = `render/<폴더>/` (scene.js + unit.json → MP4). 공통 코드는 `render/_lib/`.
모든 단위 공통 스타일(2026-09-19 개정): 슬라이드 틀·섹션 태그·제목 없이 자연스러운 영상. 상단 파랑·초록 가드와 우하단 부산대 로고만(`guard()`), 하단 자막(`SUBS` → `drawSubs`, 나중에 SRT로도 추출). '개념도', '측정값 아님', '가상 상황 연출' 같은 보조 표기는 넣지 않는다. 캡처 카드 위 작은 출처 표기만 유지.
실행: `python render/_lib/render.py render/<폴더>` (정지 화면 확인: `--stills 1.0 5.5`)
타이밍은 각 단위를 만들 때 해당 WAV의 문장 경계를 실측해 scene.js 머리 주석에 적는다.
