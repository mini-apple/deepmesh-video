# TTS_TIMING

CapCut TTS로 생성한 구간별 음성의 **실제 길이**를 기록한다.
추정값이 아니라 실측값만 적는다. 이 값이 확정돼야 씬 맵의 클립 수가 결정된다.

## 측정 방법

1. CapCut 새 프로젝트(1920×1080)를 연다.
2. `script/APPROVED_NARRATION_KR.md`의 구간별 문장을 텍스트 레이어로 넣는다.
3. 화자별로 목소리를 지정해 음성 변환한다. (해설 / 질문자 / 애덤 / 해커 / 검사원)
4. 구간별 오디오 클립을 모두 이어붙인 뒤 타임라인에서 길이를 읽어 아래 표에 적는다.
5. 소수점 첫째 자리까지 기록한다. 예: `103.4`

## 최종 길이 전망

| 항목 | 초 |
|---|---|
| 나레이션 합계 | 536 |
| ① 프리즈 정지 비트 | +2 |
| ⑥ 탐지 OFF↔ON 전환·이벤트 확인 여유 | +10~15 |
| ⑧ 크레딧 꼬리 | +5 |
| **예상 총 길이** | **약 553~558초 (9분 13초~9분 18초)** |

⑥의 실제 길이는 시연 녹화 편집에서 정해진다. 9분에 맞추려면 ⑥ 전환 여유를 5초 이내로 잡는다.

## 판정 기준

- 합계 실측이 **585초를 넘으면** 대본을 줄인다. 단, 쿠버네티스 용어 문단과 측면이동 정의는 삭감 대상에서 제외한다(교수님 지시).
- 합계가 **550초 미만이면** ⑥ 시연의 대기 구간 배속을 완화해 실제 동작을 더 길게 보여준다.
- 구간 실측이 계획보다 15% 이상 길면 해당 구간 문장을 줄이고, 클립 수를 다시 계산한다.
