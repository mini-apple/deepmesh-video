# TTS_INPUT_KR

CapCut TTS에 붙여넣을 **복사용 텍스트**. 원본은 `script/APPROVED_NARRATION_KR.md`이며, 이 파일은 TTS 입력 전용이다.

## 원본과 다른 점 (TTS 입력용 가공)

- `[화면]` 지시, 화자 표시, `**` 강조 표시를 뺐다.
- 영어 용어는 **발음만** 한글로 적었다. 자막(SRT)은 원본 표기를 쓴다.
- 문장 내용은 원본(`APPROVED_NARRATION_KR.md`)과 같다. 두 파일은 항상 함께 수정한다.

  | 원본 | TTS 입력 |
  |---|---|
  | DeepMesh (팀 이름. 시스템을 가리킬 때는 쓰지 않는다) | 딥메시 |
  | 서비스메시 / 사이드카 프록시 | 그대로 |
  | Anthropic | 앤트로픽 |
  | MSA | 엠에스에이 |
  | frontend / auth / post / comment | 프론트엔드 / 오스 / 포스트 / 코멘트 |
  | Pod | 파드 |
  | Drop / Relay / Forward | 드롭 / 릴레이 / 포워드 |

- 자리표시자는 모두 없어졌다. ⑦ 수치는 2026 졸업과제 포스터 결론의 실측값으로 채웠고, ⑤의 Relay 지연 문장은 삭제했다.
  ⑥의 k1 결과 자막(`[실제 터미널 결과로 확정]`)만 원본 대본에 남아 있으며, 이는 나레이션이 아니라 화면 자막이다.
- 긴 박스는 TTS 글자 수 제한에 걸리지 않도록 `a` / `b`로 나눴다. 같은 화자이므로 **같은 목소리로 바로 뒤에 이어 붙이면** 된다.

## 사용법

1. 박스 하나(회색 코드 블록 하나)를 통째로 복사해 CapCut 텍스트 클립 하나에 붙여넣는다.
2. 박스 제목의 **화자** 목소리로 음성을 생성한다.
3. 다음 박스는 앞 음성 끝에 틈 없이 붙인다. 화자 전환 쉼은 측정 후 계산에서 더한다.
4. 구간 하나가 끝나면 `edit/tts/TTS_0N_구간명.wav`로 음성만 내보낸다.

```text

```

```text

```

### 05-3a · 해설

```text
정상품의 모습만 외워 두면 됩니다. 여기에 쓰는 두 번째 기술이 딥러닝 이상탐지 모델입니다. 외워 둔 정상과 다르게 생긴 것이 나오면 이상으로 판단합니다. 공격은 불량품처럼 드물기 때문에, 공격 데이터 없이 평소 나가던 정상 이미지만으로 학습시킵니다. 이렇게 학습한 검사원은 사람 눈에 거의 똑같아 보이는 것도 미세한 차이를 잡아냅니다.
```

### 05-3b · 해설

```text
그런데 의심만으로 막으면 정상 생산까지 멈출 수 있습니다. 그래서 한 번 더 확인합니다.
```

## ⑥ 시연 → `TTS_06_시연.wav`

> 이 구간은 나레이션만 잰다. 실제 영상 길이는 시연 동작 시간으로 채우므로 나레이션보다 길다.
> 비유 없이 실제 용어로만 설명한다. 화자는 전부 해설(해커·검사원 대사 없음).
> 06-2(k1 설명)와 06-5(r1 설명)는 **화면만 AI 생성 영상**이다. 나레이션은 그대로 녹음한다.

### 06-1 · 해설 (정상 상태)

```text
그럼 이제 이상 트래픽이 정말 막히는지 실제 시스템에서 확인해보겠습니다. 버추얼머신 네 대로 쿠버네티스 클러스터를 세우고 저희 게시판을 올렸습니다. 네 개의 서비스가 각각 파드로 돌아가고, 모든 파드에는 사이드카 프록시가 붙어 있습니다. 이 화면은 관리자가 전체 클러스터 현황을 볼 수 있는 대시보드입니다. 지금은 정상적인 트래픽 부하를 주고있고, 트래픽이 모두 초록색 포워드 간선으로 보이는 것을 확인할 수 있습니다.
```

### 06-2 · 해설 (k1 설명)

```text
그럼 첫 번째 공격을 진행해보겠습니다. 오스 파드 하나가 이미 탈취됐다고 가정합니다. 공격자는 파드에 기본으로 들어 있는 서비스 계정 토큰으로 쿠버네티스 API 서버에 접속해, 클러스터 정보를 캐려 합니다.
```

```text
먼저 사이드카 프록시를 끈 상태입니다. 오스는 평소 API 서버를 호출할 일이 없지만, 감시하는 장치가 없으면 이 요청은 그대로 API 서버까지 도달합니다.
```
